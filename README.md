# Starlight-Audio-Player
My open source code for a customizable audio player. Feel free to use this for your website. To see a working example, please go to https://mommifoxxi.love/Starlight-Audio-Player.

<img width="1666" height="927" alt="image" src="https://github.com/user-attachments/assets/3d6ad1ae-9122-4313-8437-be4d4b490090" />

Use the index.html file to edit text and the style.css file to change colors and images. Both files contain comments to help guide customization.

The search table is powered by the audios.json file in the "metadata" folder and needs to be filled out with the relevant information. Use a tool such as https://csvjson.com to take a table/spreadsheet and convert it to the json format. Audio files can be placed into the "audios" folder, and the filenames listed in the audios.json file need to match for the player to work. I recommend using mp3 files to save on space. Images can be placed in the "img" folder.

My site is hosted with https://neocities.org, but this should work across hosts.
